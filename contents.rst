
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
Process Improvement Using Data
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

.. only:: html

   This book is free to read here, or to download as a `PDF <https://learnche.org/pid/PID.pdf>`_.
   It covers the methods engineers and scientists use with process data: visualization,
   univariate statistics, process monitoring, least squares models, designed experiments, and
   latent variable models such as PCA and PLS.

   The Python examples in chapters 1 to 6 each have a **Run in browser** button, as under the
   raincloud plot in :doc:`box plots <data-visualization/box-plots>`. A click starts Python in
   your browser tab, runs the example on its data set and draws the result under the code, with
   nothing to install. The examples use `process-improve
   <https://github.com/kgdunn/process-improve>`_, the book's open-source Python package.
