# References to add to literature.learnche.org

This file tracks references that are cited in the PID book but are not yet
in the literature catalogue at <https://literature.learnche.org>. As entries
get added to the catalogue and re-exported, the citations in the book can be
upgraded from plain text or external link to a catalogue hyperlink.

## How to use this file

1. When adding citations to the book, if a cited work has no matching entry
   in the JSON export, add it here.
2. Group entries by the chapter where they appear, so the user can decide
   on priority.
3. Once an entry has been added to literature.learnche.org and re-exported,
   delete it from this list and update the corresponding citation in the
   book to point at the new catalogue URL.
